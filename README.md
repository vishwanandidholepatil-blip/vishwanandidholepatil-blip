## Project showcase

### Smart IV Monitor
**Status: working weight-sensing prototype; further development in progress**

A research prototype exploring how changes in fluid weight and drip activity could support IV monitoring alerts. I've worked with an ESP32, a load cell, and an HX711 module to read weight, calibrate measurements, and experiment with LED and buzzer feedback.

The next stage is to add optical drip sensing and bring the readings together in a Wi-Fi dashboard. This is a water-only bench prototype, not a clinically validated medical device.

**Tools:** ESP32 · HX711 · Load cell · Arduino IDE  
**Current focus:** Sensor calibration, repeatable testing, and alert behaviour.

### MyFolio
**Status: early MVP in development**

I'm building MyFolio around a simple problem: students need a better way to show what they can do beyond a résumé. The planned platform brings together student portfolios, competition discovery, teammate matching, and career opportunities.

Work so far includes Supabase authentication, profile and portfolio data, and access-control rules. The next step is a focused progressive web app. TalentScore, a proposed 1,000-point profile assessment, is still being designed.

**Tools:** Vite · Supabase · Netlify · VS Code  
**Project domain:** [myfolio.co.in](https://myfolio.co.in) — the product is still in development.
